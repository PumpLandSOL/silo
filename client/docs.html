The private layer, in detail.

SILO is a private layer 2. It produces its own blocks of private transactions and settles every batch to the SiloRollup contract on Robinhood Chain (chain id 4663).

Architecture

  • Sequencer node. Produces an L2 block every 4 seconds. Each block header (height, parent, timestamp, tx root) is hashed with keccak-256 and signed by the sequencer's secp256k1 key, the same key that posts to Robinhood Chain.
  • SiloRollup. A Solidity contract on Robinhood Chain. It holds bridged ETH, emits a Deposit event per deposit, records each batch (stateRoot, txRoot, block range) and pays the exits in it. Batches must chain: each starts where the last ended.
  • Wallet. Keys, scanning, ring signatures and proofs all run in your browser. The node never sees a seed.

A private transaction

  • Inputs: each input is an MLSAG ring signature over 16 outputs from the global set, plus a key image that marks the real one spent without saying which it was.
  • Outputs: a one-time stealth key, a Pedersen commitment to the amount, an encrypted amount, and a 48-bit range proof. Quantum (siloq1) outputs also carry a 1,088-byte ML-KEM-768 ciphertext used for payment detection.
  • Balance: the node checks that the input commitments equal the output commitments plus the fee (and any exit) without learning a single amount.

Deposits

Call deposit(bytes l2addr) on SiloRollup with ETH (minimum 0.001, in whole micro-ETH). The node watches the contract's events and mints the deposit in its next block as an output to l2addr. Deposits over 100 ETH are split across several outputs.

SiloRollup.deposit(bytes l2addr) payable
event Deposit(uint256 indexed id, address indexed from, uint256 amount, bytes l2addr)

Withdrawals

A withdrawal is a normal private transaction with one extra public field, exit = { to, amount }. The exit is part of the signed message, so changing it breaks the ring signatures. The sequencer includes every pending exit in the next batch, and the contract pays it and records its L2 transaction id so it can never be paid twice.

SiloRollup.postBatch(uint64 n, uint64 fromBlock, uint64 toBlock, bytes32 stateRoot, bytes32 txRoot, Exit[] exits)
struct Exit { bytes32 txid; address to; uint256 amount; }

Roots

txRoot is keccak-256 over the hashes of every L2 block in the batch. stateRoot is keccak-256 over the output set, the spent key images and the last block height. Anyone running the node from the same history reproduces both.

Trust model

SILO launches at Stage 0, like most rollups at launch: one sequencer orders transactions and posts batches, and the contract trusts it to post honest roots. Everything that crosses the bridge is public on Robinhood Chain. Next on the roadmap: validity proofs over each batch, and a forced-exit path that lets anyone withdraw through the contract directly.
